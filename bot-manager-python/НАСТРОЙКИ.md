# Rim Manager system — описание настроек

## Где хранятся настройки

- **При запуске из папки проекта:** `config.json` и `.env` в папке с программой.
- **При запуске exe:** сначала используется папка рядом с exe; при отсутствии прав записи — `%APPDATA%\RimManagerSystem\`.

После нажатия «Сохранить» все параметры пишутся в эти файлы и при следующем запуске подхватываются.

---

## Один токен на Online и Update бота

**Да, можно использовать один и тот же Discord-токен** для обоих ботов (Online Bot и Update Bot), если оба приложения созданы в одном боте в Discord Developer Portal. Тогда в настройках просто укажите один и тот же токен в полях «Online Bot Token» и «Update Bot Token».

Если боты разные — у каждого свой токен.

## Список настроек и за что они отвечают

### Токены ботов
| Поле | Назначение |
|------|------------|
| **Online Bot Token** | Токен бота для панели: онлайн, статус сервера, кнопки старт/стоп/рестарт в Discord. |
| **Update Bot Token** | Токен бота для обновления сервера и модов (SteamCMD, пресеты и т.п.). |

### config.json (Discord и сервер)
| Поле | Назначение |
|------|------------|
| **Server ID** | ID сервера Discord (гильдии). |
| **Webhook URL** | URL вебхука (если используется). |
| **Client ID** | ID приложения бота в Discord (если нужен для OAuth и т.п.). |
| **Arma Server IP** | IP сервера для отображения статуса и онлайна (например `109.248.4.45`). |
| **Arma Server Port** | Порт сервера (например `2302`). |
| **Discord Panel Channel ID** | ID канала, в котором бот показывает кнопки «Старт / Стоп / Перезагрузка» сервера. |

### Команды сервера
| Поле | Назначение |
|------|------------|
| **Команда старта сервера** | Команда или путь к bat/exe для запуска сервера (например `C:\a3server\start.bat`). |
| **Команда остановки** | Команда для остановки сервера. |
| **Команда перезагрузки** | Команда для перезапуска сервера. |

### Steamcmd и моды
| Поле | Назначение |
|------|------------|
| **Путь к steamcmd.exe** | Полный путь к `steamcmd.exe` или папка, где он лежит (например `C:\steamcmd` или `C:\steamcmd\steamcmd.exe`). |
| **Папка загрузки модов** | Папка, куда SteamCMD качает моды (например `C:\a3server`). |
| **Steam App ID** | ID игры в Steam (для Arma 3 — `107410`). |
| **ID модов Workshop** | Список ID модов из Workshop (по одному на строку) для обновления. |

### Настройки сервера (env)
| Поле | Назначение |
|------|------------|
| **A3 Server Directory** | Корневая папка сервера (например `C:\a3server`). |
| **API Port** | Порт API (если используется). |
| **CLIENT_ID** | Идентификатор клиента (если используется). |

### База данных (если используется)
| Поле | Назначение |
|------|------------|
| **DB Host, Port, User, Password, DB Name** | Параметры подключения к MySQL/базе данных. |

## Ваши значения по умолчанию

Можно один раз задать в настройках и сохранить:

- **Директория сервера / папка модов:** `C:\a3server`
- **steamcmd.exe:** `C:\steamcmd` (или `C:\steamcmd\steamcmd.exe`)
- **IP сервера:** `109.248.4.45`
- **Порт:** `2302`

Остальное (токены, Server ID, Discord Panel Channel ID, команды старта/стопа) заполняется по вашему Discord-серверу и способу запуска сервера.
