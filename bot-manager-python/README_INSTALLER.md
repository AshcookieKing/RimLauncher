# Создание установщика

## Требования

1. **Inno Setup 6** или выше
   - Скачать: https://jrsoftware.org/isdl.php
   - Установить Inno Setup
   - Добавить путь к `iscc.exe` в системный PATH
     - Обычно: `C:\Program Files (x86)\Inno Setup 6\`

## Создание установщика

### Автоматически

1. Сначала соберите приложение:
   ```bash
   build.bat
   ```

2. Затем создайте установщик:
   ```bash
   build_installer.bat
   ```

### Вручную

Если Inno Setup не в PATH, запустите компилятор напрямую:

```bash
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" BotManager.iss
```

## Что делает установщик

1. **Устанавливает приложение** в папку `C:\Program Files\Ziliron Bot Manager\`
2. **Создает ярлыки**:
   - В меню "Пуск"
   - На рабочем столе (опционально)
   - В панели быстрого запуска (опционально)
3. **Проверяет наличие Node.js** и предупреждает, если его нет
4. **Опционально устанавливает зависимости** Node.js (`npm install`)

## Структура установки

После установки структура будет следующей:

```
C:\Program Files\Ziliron Bot Manager\
├── BotManager.exe      # Основное приложение
├── icon.ico            # Иконка
├── README.md           # Документация
└── [файлы конфигурации создаются при первом запуске]
    ├── config.json
    └── .env
```

## Установка зависимостей Node.js

После установки приложения:

1. Запустите приложение один раз (файлы распакуются)
2. Скопируйте `package.json` из временной папки (обычно `%TEMP%\_MEIxxxxx\resources\`)
3. Запустите `install_node_dependencies.bat` в папке с `package.json`

Или используйте опцию в установщике "Установить зависимости Node.js".

## Удаление

Установщик создает запись в "Программы и компоненты", через которую можно удалить приложение.
