┌───────────────────────────────────────────────────────────────┐
│ ШАГ 4: ТЕСТИРОВАНИЕ                                          │
└───────────────────────────────────────────────────────────────┘

1. Откройте веб-карту:
   http://localhost:5050/

2. Выберите "Операции карты" → "Активности" → "Аванпост"

3. Кликните ПО ЦЕНТРУ КАРТЫ

4. Проверьте логи map_api (в консоли):
   Должно быть:
   [SPAWN_REQUEST] template=avanpost_1, coords: X=10250.0, Y=0.0, Z=10250.0

5. Проверьте логи Arma 3:
   C:\a3server\profiles\arma3serverprofiling_x64_*.rpt
   
   Ищите строки:
   [RIM_mapZoneSpawn] trigDB=[10250,0,10250] trigATL=[10250,XXX,10250]
   [RIM_mapZoneSpawn] OK id=... zone_uid=... pos=[10250,0,10250]

6. Проверьте в игре:
   - Подключитесь к серверу
   - Откройте карту (M)
   - Маркер должен быть В ЦЕНТРЕ КАРТЫ
   - Телепорт: player setPosATL [10250, 0, 10250]
   - Аванпост должен быть на месте, НА ЗЕМЛЕ

  В игре:       маркер в центре, аванпост на земле

Формат ATL: [east, AGL, north]

  pos_x = восток/запад (0-20500)
  pos_y = высота над землей (обычно 0-500)
  pos_z = север/юг (0-20500)
