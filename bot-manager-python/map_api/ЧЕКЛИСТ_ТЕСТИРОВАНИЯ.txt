□ Остановить Arma 3 сервер
  taskkill /F /IM arma3server_x64.exe

□ (Опционально) Очистить очередь спавна
  DELETE FROM arma_map_zone_spawn_queue WHERE server_id = 1;

□ Запустить map_api
  cd C:\rim_online_bot\bot-manager-python\map_api
  run_map_api.cmd

┌───────────────────────────────────────────────────────────────┐
│ ТЕСТ 1: СПАВН ЧЕРЕЗ ВЕБ-ИНТЕРФЕЙС                            │
└───────────────────────────────────────────────────────────────┘

□ Открыть веб-карту
  http://localhost:5000/

□ Выбрать режим "Активности"
  Операции карты → Активности → Аванпост

□ Кликнуть по центру карты
  (примерно в середине видимой области)

□ Проверить статус
  Должно быть: "Аванпост в очереди · X дройдов · Y техники · zone_uid"

□ Проверить логи Python (в консоли map_api)
  Должна быть строка:
  [SPAWN_REQUEST] template=avanpost_1, coords: X=10250.0, Y=0.0, Z=10250.0
  
  ✓ X ≈ 10250 (восток)
  ✓ Y = 0 (высота)
  ✓ Z ≈ 10250 (север)

┌───────────────────────────────────────────────────────────────┐
│ ТЕСТ 2: ПРОВЕРКА В ARMA 3                                    │
└───────────────────────────────────────────────────────────────┘

□ Запустить Arma 3 сервер
  cd C:\a3server
  START.bat

□ Дождаться загрузки миссии
  (примерно 1-2 минуты)

□ Открыть логи Arma 3
  C:\a3server\mpmissions\Rim_Conflict_base.Kapaulio\arma3server_*.rpt

□ Найти строки спавна
  Искать: [RIM_mapZoneSpawn]
  
  Должно быть:
  [RIM_mapZoneSpawn] trigDB=[10250,0,10250] trigATL=[10250,XXX,10250] id=...
  [RIM_mapZoneSpawn] OK id=... zone_uid=... pos=[10250,0,10250]
  
  ✓ trigDB = [10250, 0, 10250]
  ✓ trigATL = [10250, 50-150, 10250] (высота зависит от рельефа)

□ Подключиться к серверу в игре

□ Открыть карту (клавиша M)

□ Найти маркер зоны
  ✓ Маркер должен быть в центре карты
  ✗ НЕ внизу карты (юго-запад)
  ✗ НЕ в углу

□ Телепортироваться к зоне
  Открыть консоль (Ctrl+D или через Zeus)
  player setPosATL [10250, 0, 10250]

□ Проверить аванпост визуально
  ✓ Стены и башни на месте
  ✓ Объекты на земле (не в воздухе)
  ✓ НПС патрулируют
  ✓ Техника на земле

□ Тест северо-восточного угла
  Кликнуть в правом верхнем углу карты
  Ожидается: X≈20500, Y=0, Z≈20500

□ Тест произвольной точки

  Проверить что маркер появляется в месте клика
