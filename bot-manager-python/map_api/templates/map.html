Как пользоваться

  1. Слева сворачиваемые блоки: веб-метка, рисование зон, операции (🏕 активности · 📜 квесты · ⚔ атака).
  2. Галочки справа — слои карты: люди, машины, маркеры и т.д.
  3. Веб-метка: в левой панели включите режим постановки (или кнопка 📍), выберите значок и при необходимости подпись, затем клик по карте. {% if write_key_required %}Без ключа в шапке не сохранится.{% endif %}
  4. Активности / квесты / атака: блок «Операции», вкладка с иконкой, затем клик по карте (или маршрут для колонны/патруля).
  5. Справка по карте мира: атлас.
