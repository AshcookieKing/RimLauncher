ШАГ 2: ТЕСТ ПАТРУЛЯ
═══════════════════════════════════════════════════════════════

1. Откройте веб-карту: http://localhost:5050/map

2. Выберите режим "Патруль" (patrol)

3. Кликните на карте в ЦЕНТРЕ (примерно 10250, 10250):
   - Это будет точка спавна
   - Запомните где кликнули!

4. Кликните еще 2-3 точки для маршрута

5. Нажмите "Отправить маршрут"

6. Проверьте логи map_api - должны быть строки:
   [ROUTE_DEBUG] action=spawn_patrol, px=..., py=..., pz=...
   [ROUTE_DEBUG] payload header: ...

7. Подождите 10-20 секунд

8. Проверьте логи Arma 3 (C:\a3server\profiles\*.rpt):
   Найдите строки:
   [RIM_mapAdmin] spawn_route begin type=patrol
   [RIM_mapAdmin] spawn_route patrol u=1/... posATL=[...]
   
   ВАЖНО: posATL должен быть примерно [10250, 0, 10250]
   НЕ должно быть [10250, 0, 0] или [0, 0, 10250]!

9. Зайдите в игру и проверьте:
   - Патруль должен быть в центре карты
   - НЕ внизу карты!
