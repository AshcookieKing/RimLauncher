## Как тестировать

### Быстрый тест (5 минут)

1. **Остановить Arma 3**
   ```cmd
   taskkill /F /IM arma3server_x64.exe
   ```

2. **Запустить map_api**
   ```cmd
   cd C:\rim_online_bot\bot-manager-python\map_api
   run_map_api.cmd
   ```

3. **Спавн тестового аванпоста**
   - Открыть http://localhost:5000/
   - Выбрать "Активности" → "Аванпост"
   - Кликнуть по центру карты

4. **Проверить логи Python**
   В консоли должно быть:
   ```
   [SPAWN_REQUEST] template=avanpost_1, coords: X=10250.0, Y=0.0, Z=10250.0
   ```

5. **Запустить Arma 3**
   ```cmd
   cd C:\a3server
   START.bat
   ```

6. **Проверить логи Arma 3**
   В файле `arma3server_*.rpt` должно быть:
   ```
   [RIM_mapZoneSpawn] trigDB=[10250,0,10250] trigATL=[10250,XXX,10250]
   ```

7. **Проверить в игре**
   - Подключиться к серверу
   - Открыть карту (M)
   - Маркер должен быть в центре карты
   - Телепорт: `player setPosATL [10250, 0, 10250]`
   - Аванпост должен быть на месте, на земле

## Диагностика

### Если аванпост внизу карты
- **Симптом:** Z ≈ 0 в логах
- **Причина:** JavaScript неправильно вычисляет pos_z
- **Решение:** Проверить функцию latLngToArma

### Если аванпост в воздухе
- **Симптом:** Y >> 0 в логах (например Y=10250)
- **Причина:** Координаты Y и Z перепутаны
- **Решение:** Проверить что код не меняет координаты местами

### Если спавн только по оси X
- **Симптом:** Z всегда = 0
- **Причина:** latLngToArma возвращает pos_z = 0
- **Решение:** Проверить режим карты и формулу

## Дополнительная информация

### Система координат Arma 3 ATL
- **pos_x** = восток/запад (east/west)
- **pos_y** = высота над землей (AGL)
- **pos_z** = север/юг (north/south)

### Карта Kapaulio
- Размер: 20500 x 20500 метров
- Центр: [10250, 0, 10250]
- Юго-запад: [0, 0, 0]
- Северо-восток: [20500, 0, 20500]
