## 🎯 Система координат Arma 3

### ATL (Above Terrain Level)
Формат: `[east, AGL, north]`

- **pos_x** = восток/запад (east/west) - горизонтальная ось X
- **pos_y** = высота над землей (AGL) - вертикальная ось
- **pos_z** = север/юг (north/south) - горизонтальная ось Z

### Карта Kapaulio (20500x20500)
- Юго-запад: `[0, 0, 0]`
- Центр: `[10250, 0, 10250]`
- Северо-восток: `[20500, 0, 20500]`

## 🔍 Поток данных

```
Веб-карта (JavaScript)
  ↓ latLngToArma(e.latlng)
  ↓ pos_x=восток, pos_y=0, pos_z=север
  ↓
Python API (app.py)
  ↓ INSERT INTO arma_map_zone_spawn_queue
  ↓ pos_x, pos_y, pos_z
  ↓
База данных (MySQL)
  ↓ SELECT pos_x, pos_y, pos_z
  ↓
Arma 3 SQF (fn_mapZoneSpawnLoop.sqf)
  ↓ setPosATL [_px, высота, _pz]
  ↓
Игра (триггер и композиция)
  ✓ Правильная позиция на карте
```

## 🐛 Диагностика

### Проблема: Аванпост внизу карты
- **Симптом:** Z ≈ 0 в логах
- **Причина:** JavaScript неправильно вычисляет pos_z
- **Файл:** `templates/map.html` (функция latLngToArma)

### Проблема: Аванпост в воздухе
- **Симптом:** Y >> 0 в логах (например Y=10250)
- **Причина:** Координаты Y и Z перепутаны
- **Решение:** Проверить что код не меняет координаты местами

### Проблема: Спавн только по оси X
- **Симптом:** Z всегда = 0
- **Причина:** latLngToArma возвращает pos_z = 0
- **Решение:** Проверить режим карты (TILE_MODE)

## 💡 Советы

1. **Всегда проверяйте логи** - они покажут где именно проблема
2. **Очищайте очередь** перед тестированием - старые данные могут мешать
3. **Тестируйте центр карты** - там легче всего увидеть проблему
4. **Используйте чеклист** - он поможет не пропустить шаги

## 📞 Поддержка

Если проблема сохраняется:
1. Проверьте все файлы из списка "Важные файлы"

4. Перезапустите map_api и Arma 3 сервер
5. Повторите тест с логированием
