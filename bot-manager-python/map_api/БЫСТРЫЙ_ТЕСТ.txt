  БЫСТРЫЙ ТЕСТ КООРДИНАТ СПАВНА ЗОН
═══════════════════════════════════════════════════════════════

ШАГ 1: ОСТАНОВИТЬ ARMA 3
─────────────────────────────────────────────────────────────
  taskkill /F /IM arma3server_x64.exe

ШАГ 2: ЗАПУСТИТЬ MAP_API
─────────────────────────────────────────────────────────────
  cd C:\rim_online_bot\bot-manager-python\map_api
  run_map_api.cmd

ШАГ 3: ОТКРЫТЬ ВЕБ-КАРТУ
─────────────────────────────────────────────────────────────
  http://localhost:5000/

ШАГ 4: СПАВН ТЕСТОВОГО АВАНПОСТА
─────────────────────────────────────────────────────────────
  1. Выбрать "Операции карты" → "Активности"
  2. Выбрать "Аванпост"
  3. Кликнуть ТОЧНО ПО ЦЕНТРУ КАРТЫ
  4. Проверить статус: "Аванпост в очереди"

ШАГ 5: ПРОВЕРИТЬ ЛОГИ PYTHON
─────────────────────────────────────────────────────────────
  В консоли map_api должна быть строка:
  
  [SPAWN_REQUEST] template=avanpost_1, coords: X=10250.0, Y=0.0, Z=10250.0
  
  ✓ ПРАВИЛЬНО: X≈10250, Y=0, Z≈10250
  ✗ НЕПРАВИЛЬНО: X≈10250, Y=10250, Z=0 (Y и Z перепутаны)

ШАГ 6: ЗАПУСТИТЬ ARMA 3
─────────────────────────────────────────────────────────────
  cd C:\a3server
  START.bat

ШАГ 7: ПРОВЕРИТЬ ЛОГИ ARMA 3
─────────────────────────────────────────────────────────────
  Открыть: C:\a3server\mpmissions\Rim_Conflict_base.Kapaulio\arma3server_*.rpt
  
  Искать строки:
  [RIM_mapZoneSpawn] trigDB=[10250,0,10250] trigATL=[10250,XXX,10250]
  [RIM_mapZoneSpawn] OK id=... zone_uid=... pos=[10250,0,10250]
  
  ✓ ПРАВИЛЬНО: trigDB=[10250, 0, 10250]
  ✗ НЕПРАВИЛЬНО: trigDB=[10250, 10250, 0] (Y и Z перепутаны)

ШАГ 8: ПРОВЕРИТЬ В ИГРЕ
─────────────────────────────────────────────────────────────
  1. Подключиться к серверу
  2. Открыть карту (M)
  3. Найти маркер зоны
  
  ✓ ПРАВИЛЬНО: Маркер в центре карты
  ✗ НЕПРАВИЛЬНО: Маркер внизу карты (юго-запад)
  
  4. Телепортироваться: player setPosATL [10250, 0, 10250]
  5. Проверить аванпост:
     ✓ На правильном месте (центр карты)
     ✓ На земле (не в воздухе)
     ✓ Не внизу карты

═══════════════════════════════════════════════════════════════
  ДИАГНОСТИКА
═══════════════════════════════════════════════════════════════

ПРОБЛЕМА: Аванпост внизу карты
  Причина: Z = 0 вместо Z = 10250
  Решение: Проверить latLngToArma в map.html

ПРОБЛЕМА: Аванпост в воздухе
  Причина: Y = 10250 вместо Y = 0
  Решение: Координаты Y и Z перепутаны

ПРОБЛЕМА: Только по оси X
  Причина: Z всегда = 0
  Решение: Проверить режим карты (TILE_MODE)

═══════════════════════════════════════════════════════════════
  ОЖИДАЕМЫЕ ЗНАЧЕНИЯ ДЛЯ ЦЕНТРА КАРТЫ
═══════════════════════════════════════════════════════════════

  JavaScript:  X=10250, Y=0, Z=10250
  Python API:  X=10250, Y=0, Z=10250
  База данных: X=10250, Y=0, Z=10250
  Arma trigDB: [10250, 0, 10250]
  Arma trigATL: [10250, 50-150, 10250]
  В игре: центр карты, на земле
