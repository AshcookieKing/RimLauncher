При попытке запуска map_api возникает ошибка:
  ModuleNotFoundError: No module named 'pymysql'

Это означает что не установлены зависимости Python.

┌───────────────────────────────────────────────────────────────┐
│ РЕШЕНИЕ 1: Установка через pip (рекомендуется)              │
└───────────────────────────────────────────────────────────────┘

Откройте командную строку (cmd) и выполните:

  cd C:\rim_online_bot\bot-manager-python\map_api
  pip install pymysql

Если возникает ошибка SSL/SOCKS, попробуйте:

  pip install pymysql --trusted-host pypi.org --trusted-host files.pythonhosted.org

Или установите все зависимости:

  pip install -r requirements.txt --trusted-host pypi.org --trusted-host files.pythonhosted.org

┌───────────────────────────────────────────────────────────────┐
│ РЕШЕНИЕ 2: Установка через Python напрямую                  │
└───────────────────────────────────────────────────────────────┘

  python -m pip install --user pymysql --trusted-host pypi.org --trusted-host files.pythonhosted.org

┌───────────────────────────────────────────────────────────────┐
│ РЕШЕНИЕ 3: Скачать и установить вручную                     │
└───────────────────────────────────────────────────────────────┘

1. Скачать pymysql:
   https://pypi.org/project/PyMySQL/#files
   
2. Скачать файл PyMySQL-X.X.X-py3-none-any.whl

3. Установить:
   pip install C:\путь\к\PyMySQL-X.X.X-py3-none-any.whl

┌───────────────────────────────────────────────────────────────┐
│ ПРОВЕРКА УСТАНОВКИ                                           │
└───────────────────────────────────────────────────────────────┘

После установки проверьте:

  python -c "import pymysql; print('pymysql установлен!')"

Должно вывести: pymysql установлен!

┌───────────────────────────────────────────────────────────────┐
│ ЗАПУСК MAP_API                                               │
└───────────────────────────────────────────────────────────────┘

После установки зависимостей запустите:

  cd C:\rim_online_bot\bot-manager-python\map_api
  python app.py

Или через батник:

  cd C:\rim_online_bot\bot-manager-python
  run_map_api.cmd

┌───────────────────────────────────────────────────────────────┐
│ АЛЬТЕРНАТИВА: Использовать существующий venv                │
└───────────────────────────────────────────────────────────────┘

Если у вас уже есть виртуальное окружение с установленными
зависимостями, активируйте его перед запуском:

  cd C:\rim_online_bot\bot-manager-python
  venv\Scripts\activate
  cd map_api
  python app.py
