## ✅ ПРОБЛЕМА 2: Техника и NPC на веб-карте показываются внизу
**Статус:** ИСПРАВЛЕНО (требует тестирования)

**Описание:**
- В игре: техника и NPC в правильных позициях ✓
- На веб-карте: показывались внизу карты (только по оси X) ✗

**Причина найдена:**
JavaScript функции `xzFromMapLiveEntity()` и `xzHorizontalFromDbRow()` использовали эвристику которая пыталась "угадать" где север - в `pos_y` или в `pos_z`. Эта эвристика ломала координаты для объектов на земле (с маленьким `pos_y`).

**Что исправлено:**
- `templates/map.html` - функция `xzFromMapLiveEntity()`: теперь просто возвращает `{ x: pos_x, z: pos_z }` без эвристики
- `templates/map.html` - функция `xzHorizontalFromDbRow()`: теперь просто возвращает `{ x: pos_x, z: pos_z }` без сложной логики

**Файлы изменены:**
- `templates/map.html` (исправлены функции координат)

**Как тестировать:**
1. Перезапустите map_api
2. Откройте http://localhost:5050/map
3. Проверьте что техника, NPC, объекты показываются в правильных местах
4. Проверьте что игрок показывается правильно при заходе
