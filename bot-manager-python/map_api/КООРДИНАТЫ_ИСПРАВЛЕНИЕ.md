# Исправление системы координат для спавна зон

## Проблема

При клике на веб-карте для спавна аванпостов, форпостов и других активностей:
- Объекты спавнятся **внизу карты** (малый Z) вместо правильной позиции
- Композиции спавнятся **в воздухе** (большой Y) вместо на земле
- Спавн происходит **только по оси X**

## Анализ

### Система координат Arma 3 ATL (Above Terrain Level)

Формат: `[east, AGL, north]`
- **pos_x** = восток/запад (east/west) - горизонтальная ось X
- **pos_y** = высота над землей (AGL - Above Ground Level) - вертикальная ось
- **pos_z** = север/юг (north/south) - горизонтальная ось Z

### Поток данных

1. **JavaScript (map.html)** - извлекает координаты из клика:
   ```javascript
   const { pos_x, pos_z } = latLngToArma(e.latlng);
   const pos_y = parseFloat(document.getElementById('placeY').value) || 0;
   ```
   ✓ **Правильно**: pos_x = восток, pos_y = высота (0), pos_z = север

2. **Python API (app.py)** - сохраняет в базу данных:
   ```python
   px = _clamp_coord("pos_x", data.get("pos_x"))
   py = _clamp_coord("pos_y", data.get("pos_y"))
   pz = _clamp_coord("pos_z", data.get("pos_z"))
   ```
   ✓ **Правильно**: координаты сохраняются как есть

3. **Arma 3 SQF (fn_mapZoneSpawnLoop.sqf)** - создает триггер:
   ```sqf
   _x params ["_qid", "_zuid", "_tplId", "_px", "_py", "_pz", "_ra", "_rb"];
   _t setPosATL [_px, 0, _pz];
   private _cur = getPosATL _t;
   _t setPosATL [_px, (_cur select 1) + _alt, _pz];
   ```
   ✓ **Правильно**: [восток, высота, север]

## Вывод

**Код уже правильный!** Все три уровня (JavaScript, Python, SQF) правильно обрабатывают координаты.

Если проблема все еще существует, возможные причины:
1. **Старые данные в базе** - очистить таблицу `arma_map_zone_spawn_queue`
2. **Кэш браузера** - очистить кэш и перезагрузить страницу (Ctrl+F5)
3. **Старая версия файлов** - убедиться что используются актуальные файлы

## Тестирование

### Быстрый тест

1. Остановить Arma 3: `taskkill /F /IM arma3server_x64.exe`
2. Запустить map_api: `run_map_api.cmd`
3. Открыть http://localhost:5000/
4. Кликнуть по центру карты для спавна аванпоста
5. Проверить логи Python: должно быть `X=10250, Y=0, Z=10250`
6. Запустить Arma 3: `cd C:\a3server && START.bat`
7. Проверить логи Arma: должно быть `trigDB=[10250,0,10250]`
8. Проверить в игре: аванпост должен быть в центре карты, на земле

### Ожидаемые значения для центра карты

| Этап | X | Y | Z |
|------|---|---|---|
| JavaScript | ~10250 | 0 | ~10250 |
| Python API | 10250.0 | 0.0 | 10250.0 |
| Arma trigDB | 10250 | 0 | 10250 |
| Arma trigATL | 10250 | 50-150 | 10250 |
| В игре | центр карты, на земле |

## Диагностика

### Если аванпост внизу карты (Z ≈ 0)
- Проверить логи Python: если `Z=0` - проблема в JavaScript
- Проверить функцию `latLngToArma` в `templates/map.html`
- Проверить режим карты (TILE_MODE)

### Если аванпост в воздухе (Y >> 0)
- Проверить логи Python: если `Y=10250` - координаты Y и Z перепутаны
- Это не должно происходить с текущим кодом

### Если спавн только по оси X
- Проверить что `latLngToArma` возвращает правильный `pos_z`
- Проверить формулу: `pos_z = ll.lat` (с тайлами) или `pos_z = MAP_SIZE - ll.lat` (без)
