# Bot Manager - Python версия

Десктопное приложение для управления Discord ботами на Python с PyQt5.

## Установка

1. Установите Python 3.8 или выше.
2. Установите зависимости одним из способов:
   - **Через batch-файл:** запустите `setup.bat` — он установит все Python-зависимости (в т.ч. PyQt5).
   - **Через установщик setup.exe:** соберите его командой `build_setup.bat`, затем запустите `setup.exe` в папке проекта — он выполнит `pip install -r requirements.txt`.
   - **Вручную:**
     ```bash
     pip install -r requirements.txt
     ```

## Запуск

```bash
python main.py
```

## Структура проекта

Все файлы ботов должны находиться в папке `resources/`:
```
bot-manager-python/
├── resources/          # Все файлы ботов (включаются в exe)
│   ├── onlinebot.js
│   ├── updatebot.js
│   ├── commands/
│   ├── public/
│   ├── config.json
│   └── package.json
├── main.py            # Основной файл приложения
├── BotManager.spec    # Конфигурация PyInstaller
└── build.bat          # Скрипт сборки
```

## Подготовка файлов

Если файлы ботов находятся в родительской папке, используйте скрипт для организации:
```bash
organize_files.bat
```

Этот скрипт автоматически переместит все необходимые файлы в папку `resources/`.

## Сборка в exe

Для создания исполняемого файла используйте готовый скрипт:
```bash
build.bat
```

**Важно**: При сборке все файлы из папки `resources/` будут включены в exe файл.

## Создание установщика

Для создания установщика Windows:

1. Сначала соберите приложение (`build.bat`)
2. Затем создайте установщик:
   ```bash
   build_installer.bat
   ```

**Требования**: Inno Setup 6 или выше (см. `README_INSTALLER.md`)

Установщик автоматически:
- Установит приложение в Program Files
- Создаст ярлыки
- Проверит наличие Node.js
- Опционально установит зависимости Node.js

### Использование упакованного приложения

После сборки вы получите один exe файл в папке `dist/`. 

**Для работы ботов необходимо:**

1. **Node.js** должен быть установлен на компьютере
2. Установите зависимости Node.js:
   - При первом запуске exe файла, все файлы ботов распаковываются во временную папку
   - Скопируйте `package.json` из временной папки (обычно `%TEMP%\_MEIxxxxx\resources\`)
   - Выполните `npm install` в папке с `package.json`

## Возможности

- ✅ Запуск, остановка и перезапуск ботов
- 📋 Просмотр логов в реальном времени
- ⚙️ Настройка всех параметров из config.json и .env
- 🎨 Темно-пурпурный интерфейс
- 📊 Отображение статуса каждого бота
- 🖥️ **Вкладка «Сервер»:** старт/стоп/перезагрузка сервера (команды настраиваются), отображение статуса онлайна (кол-во игроков)
- 📦 **Вкладка «Моды»:** обновление модов через SteamCMD (путь к steamcmd, App ID, список Workshop ID)
- 🔗 **Гибкие настройки:** канал Discord для панели (старт/стоп/рестарт), команды сервера, пути SteamCMD — всё в ⚙️ Настройках

## Структура

- `main.py` - Главный файл приложения
- `requirements.txt` - Зависимости Python
- `config.json` - Локальная конфигурация приложения
